Asistente Ciudadano

Esta página simula el sitio web de un organismo público con el Asistente Ciudadano integrado como widget (botón flotante, abajo a la derecha).

Probá preguntarle, por ejemplo: "¿Qué necesito para habilitar un comercio?", "¿Cómo renuevo la cédula?" o "¿Dónde pago la contribución inmobiliaria?".

Una plataforma, muchos asistentes

El mismo servicio puede alojar un asistente por organismo o dominio. Cada uno tiene detrás un orquestador con agentes especialistas y su propia base de conocimiento. Probá otro ejemplo real:

→ Asistente de Sanidad Animal (MGAP) — enfermedades del ganado, protocolos de aviso, controles y trazabilidad.

Integración en su sitio

El widget se integra agregando una única línea antes de cerrar </body>:

<script src="https://SU-SERVICIO/widget.js" defer></script>

Para elegir un asistente específico se agrega data-bot-id:
<script src="https://SU-SERVICIO/widget.js" data-bot-id="mgap-ganado" defer></script>

La API también puede consumirse directamente; la documentación está en specs/openapi.yaml del repositorio.
